智慧體重管理 V3.9.1e｜報表匯出圖表空白修正版
=========================================

【為什麼需要修正】
在 V3.9.1d 的 HTML／PDF 分析報告中，四張「期間趨勢圖」原本透過 canvas.toDataURL() 從網頁的 Chart.js 畫布擷取 PNG。當分析分頁尚未實際顯示、Canvas 未完成繪製或尺寸不正確時，擷取結果可能是透明／空白圖片。
另外，熱量圓環原本使用 CSS conic-gradient，Safari 儲存 PDF 時可能忽略背景顏色，使圓環變白。

【本次修改】
1. 匯出報告的「體重趨勢」改成獨立 SVG 向量圖。
2. 匯出報告的「體脂及骨骼肌重」改成獨立 SVG 向量圖。
3. 匯出報告的「內臟脂肪」改成獨立 SVG 向量圖。
4. 匯出報告的「每日熱量趨勢」改成獨立 SVG 向量圖。
5. 熱量來源圓環在匯出報告時使用 SVG 的實際色弧，避免 Safari 不列印 CSS 背景。
6. 日期區間保持動態：上述四圖與期間成效資料只用選定區間內已存在的日誌重新計算。
7. 「計畫總進度」仍從計畫開始日到最新有意義的資料日，不受分析期間切換影響。
8. 原有歷史資料、食物搜尋、營養標示 OCR、健康指標計算及 App 正式版均未更動。

【重要說明】
- 本版使用與 V3.9.1d 相同的獨立測試 localStorage 儲存鍵，方便在同一網域下沿用既有測試紀錄。正式版 index.html 不受影響。
- 圖表已改為直接從選定區間的紀錄資料重新繪製；無紀錄的日子不會被當成零值。
- 「每日熱量趨勢」保留原 V3.9.1d 每日圖表的「飲食－運動－減重目標攝取」基準，與另一個「維持體重基準｜飲食與運動熱量來源」區塊不同，標題及圖例有註明。此次修正不改動任何營養或熱量計算公式。

【GitHub Pages 安裝步驟】
1. 上傳 fitness-v391e-test.html 到 fitness-pwa 儲存庫根目錄。
2. 不要取代正式版 index.html，也不要清除 Safari 網站資料。
3. 上傳後於 Safari 開啟：
   https://het6973-yt.github.io/fitness-pwa/fitness-v391e-test.html
4. 選擇「身體組成變化」，設定例如 2026/10/15～2026/11/03。
5. 先確認網頁數值，再按「列印／存 PDF」或「匯出可閱讀 HTML 分析報告」。
6. 檢查趨勢圖四張與熱量來源圓環是否完整。
7. 若下載的是 HTML，請使用 Safari 開啟下載的 HTML 並從分享／列印選單儲存 PDF。
